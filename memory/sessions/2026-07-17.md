## Decisions
- **Backend Flask = machine de workflow durable (etat SQL) ; Code Agent = cerveau invoque par commande
  bornee** (plan/execute/replan/review/synthesize), stateless. Un appel Mesh n'execute plus un run entier.
  Seul decoupage compatible regle d'or DSS (etat jamais en RAM seule) + NON-DURABLE by design de
  l'orchestrateur + absence d'annulation Mesh + SELECT-only.
- **Dual-path** : chemin legacy INTACT (byte-identique sans token), durable seulement sur agent flague
  `durable_workflow` + gate deterministe haute precision. Le trafic simple ne paie jamais le planner.
- **Correlation = vrai JOIN SQL** (Sol) et pas jointure Python bornee (Fable, prouvee biaisee par le cap).
- **Ledger via le PROMPT** (Fable) et pas lecture SQL par l'agent : evite d'elargir les grants DB de l'agent.
- OFF par defaut (feature flag), rien deploye contre DSS.
