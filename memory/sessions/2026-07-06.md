# Session 2026-07-06 (démarrée le 2026-07-05 au soir) - Manipulation de données sans IA : agrégats DB, zone Calculer, plages de dates, unification Evidence, plugin dev_v2

## Objectif
Donner aux utilisateurs métier (profil Excel) le pouvoir de manipuler/vérifier la donnée SANS SQL et
SANS appel IA : d'abord une session de brainstorming/cadrage (webapp uniquement), puis, sur feu vert
user, l'implémentation en 3 vagues avec agents Sonnet/Opus uniquement, livrée dans un NOUVEAU plugin
coexistant `owismind_dev_v2` (prod ET dev stable intacts : démo dans quelques jours).

### Vague 1 - Spec d'agrégation serveur + premières surfaces (2 agents Opus //)
- **Backend `POST /source/aggregate`** : spec structuré `{agent, source, q, filters, group{column,bucket},
  measures[{fn,column}], limit}` ; fns whitelistées (count, count_distinct, sum, avg, min, max),
  gate numérique sur le schéma live, `DATE_TRUNC` à unité figée, LIMIT interne obligatoire (50+1),
  2e requête totals non groupée pour les % exacts, read-only + statement_timeout + throttle hérités.
  Builder pur `build_aggregate_query` (+ `NULLS LAST`), classifieurs `is_numeric_type`/`is_temporal_type`
  dans `sql_config`, validateur borné.
- **Frontend** : barre de totaux (compte DB exact), stats de colonne via sigma, vue Analyser
  (group-by 1 colonne + mesure, % du total, data-bars neutres), lien discret « Vérifier ce chiffre »
  (ouvre Evidence sur l'onglet Sources, gaté sur `meta.available`).
- **`tools/build_dev_plugin.py --v2`** : 3e plugin coexistant `owismind_dev_v2` (id, labels DEV v2,
  base Vite, staging + zip dédiés) ; `--check` OK dans les 2 modes.
- Revue adversariale (4 lentilles + réfutateurs) : 8 confirmés / 0 réfuté, tous corrigés (stale count
  sur échec de refresh, NULLS LAST, petites valeurs != « 0 », gros entiers exacts sans dérive 2^53,
  fetch lignes évité en vue Analyser, clic mort verify sur échange dégradé, aria sigma, ARIA segmenté).
- QA Playwright réelle (harnais stub `getWebAppBackendUrl` + mini-serveur) : 9/9 puis re-checks.
- **✅ VALIDÉ DSS par l'user** (screenshot dev2 : « super c'est vraiment bien ça marche »).

### Vague 2 - Retour user : zone Calculer + plages de dates + médiane (2 agents Opus //)
- Retour user : group-by trop technique pour un sales ; les métriques doivent vivre dans la zone vide
  en haut à droite SANS quitter le dataset ; plage de dates en 1-2 clics ; garder l'onglet Analyser.
- **Backend** : fn `median` (PERCENTILE_CONT(0.5), gate numérique) ; op `BETWEEN` accepté sur les
  filtres `/source/*` uniquement (exactement 2 valeurs), préservé dans `_source_conditions`.
- **Frontend** : zone **CALCULER** (select colonne + cartes KPI par TYPE : num = Somme/Moyenne/
  Médiane/Min/Max ; date = Min/Max ; texte = Valeurs distinctes), persistante (suit les filtres),
  sigma -> zone, pied réduit au compte ; **filtre de plage** sur colonnes temporelles (2 inputs month
  De/À + « Année complète » one-shot) -> chip `BETWEEN` éditable pré-rempli, bornes
  `[YYYY-MM-01, dernier-jour T23:59:59.999999]` ; « Médiane de X » dans Analyser.
- Revue : 6 confirmés / 1 réfuté, tous corrigés (classifieur temporel front = miroir EXACT du back,
  borne microseconde, count auto-réparé, récap de scope en libellé mois, aria selects, placeholder
  AAAA-MM pour le fallback texte Firefox/Safari).
- QA 10/10 (+ re-check ciblé après détection d'un run QA sur bundle pré-fix).

## Décisions
- **Tout chiffre montré = calcul DB sur le jeu filtré complet** ; un calcul client sur fenêtre
  partielle est interdit (source de mauvaises réponses). Affichage inversé : « affichage des N
  premières lignes, les calculs portent sur tout ».
- **Un seul primitif serveur** (spec d'agrégation) ; totaux, stats, top-N, buckets = presets.
- **Un seul code pour accueil et Evidence** (aggregate_core + aggregateSurface + composants bi-hôtes).
- **dev_v2 = 3e plugin coexistant** (`--v2`), jamais toucher prod/dev pendant la période de démo.
- Zone Calculer par TYPE de colonne, générique (aucun nom de colonne en dur) ; group-by relégué à
  l'onglet Analyser (conservé, à améliorer plus tard).
- Surface Evidence paresseuse (coût instance) ; chips agent verrouillées jamais transformées en plage.
