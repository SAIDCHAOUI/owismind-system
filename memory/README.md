# memory/ - mémoire d'équipe OWIsMind (versionnée git = source de vérité)

Ordre de lecture : **`CONTEXT.md`** (focus courant + chaîne des sessions + prochaines étapes, tenu lean, chargé auto)
puis **`LESSONS.md`** (base append-only, à la demande) puis **`PROJECT_STATE.md`** (état durable ; section 11 = matrice
de ce qui est réellement déployé).

- **`sessions/`** : un log par jour (`<YYYY-MM-DD>.md`), le détail complet de chaque session.
- **Gotchas techniques** : hors mémoire, dans `.claude/rules/*.md` (path-scoped, chargées auto selon les fichiers touchés).
- **Protocole d'hygiène + fin de session** : `CLAUDE.md` (section Mémoire) et `.claude/rules/memory.md`. Refresh = `/log-session`.
