- **F26 - Aura du prompt (2026-08-13, decision user "luxe")** : le nuage orange autour de la carte de prompt vit dans les tokens `--aura-orange` / `--aura-orange-strong` (par THEME, alphas < 0.15) et n'est PAS cable en dur dans PromptBar : le composant lit `var(--prompt-aura, 0 0 0 0 transparent)` (repli TRANSPARENT obligatoire - `none` est illegal dans une liste de `box-shadow`), l'hote decide. - **F27 - Morph du 1er envoi (2026-08-13, "la passation")** : `PromptBar` est HISSE hors des branches v-if de ChatView (UN seul `.prompt-wrap`, classe `in-empty` conditionnelle) - sans ca le composant etait detruit/recree a chaque 1er envoi (focus perdu, morph impossible). Geometrie pure + timings = `composables/morphSend.js` (teste node:test) ; DOM/WAAPI = `composables/useFirstSendMorph.js` ; ChatView orchestre. Regles apprises : (1) `chat.hasMessages` bascule SYNCHRONE (`exchanges.push` avant tout await, stores/chat.js) donc un watcher `flush:'pre'` mesure le "First" et `nextTick` donne le "Last" ; (2) le texte VISIBLE doit etre arme par PromptBar AVANT `chat.draft = ''` (`armFirstSend`), la charge envoyee pouvant contenir un bloc de contexte que l'user n'a jamais vu ; (3) le bloc titre doit etre mesure AVANT le patch (au moment du hook `leave` de la `<Transition>`, ChatThread est deja insere et l'a pousse vers le bas) puis fige en `position:absolute` pour liberer le flux ; (4) la bulle qui vole est un `cloneNode` de la VRAIE bulle (classes scoped conservees -> theme correct, pas de 2e source de verite) ; (5) le calque vit sur `<body>` (`.owi-morph-layer`, base.css) car `.chat` et `.main` sont en `overflow:hidden` ; (6) la carte anime `width`/`height`/`translate` et JAMAIS `scale` (un scale ecrase le texte, le filet 1px et le radius 18px, et demanderait un contre-scale du contenu) ; (7) PIEGE FLIP mesure au harness : quand on restaure AUSSI l'ancienne taille, l'inversion doit partir des bords ANCRES, sinon la carte se teleporte a la 1re image - `dx` est OBLIGATOIRE (une carte a `width` imposee se colle au bord GAUCHE de son wrap, pas de marges auto : 209px de saut en 2000px de large) et le `dy` doit etre calcule sur les bords BAS (`dyBottom`, la carte est ancree en bas de la colonne flex, donc la hauteur "hero" repousse son bord haut : 116px de saut avec un brouillon de 5 lignes) ; (8) `msg-in` vit sur `.msg`, PAS sur `.bubble` : couper l'animation de la LIGNE avant de mesurer la bulle (sinon la cible est prise pendant son `translateY(6px)` et le vol atterrit 6px trop bas) et ne pas la restaurer (le morph EST l'entree de ce message) ; (9) calque `aria-hidden="true"` (il duplique le texte du message). Garde-fous : 1er message seulement, reduced-motion, > 600 caracteres ou > 8 lignes ou colonne < 420px = pas de morph, annulation sur changement de conversation/demontage.
